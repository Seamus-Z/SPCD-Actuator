          参考 moteus：推荐顺序为 R → Ld/Lq → 编码器转圈映射 → 编码器几何补偿 → 齿槽 → Ke。
          转圈映射会以恒定 D 轴电流正反各转两圈，并以受限加速度平滑换向；生成的 64 点周期换相补偿表会保存到 Flash NVS。
          「编码器几何补偿」用恒速惯性法生成 256 点表，压磁环偏心/倾斜带来的 1/2 次速度纹波（对应 Live 上约 10% 慢正弦）。
          DM4310 建议 40 elec rad/s、1.0 A 起步；固件将转圈速度限制为 80、校准电流限制为 2.0 A。
          「锁定校准」只辨识单一全局 offset，用于低速诊断，不能替代转圈映射。
